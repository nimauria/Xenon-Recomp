# Xenon Launcher UI v7.2

This pass is focused on window chrome, profile ergonomics, responsive scaling, and fuller integration of Xenon-owned theme artwork.

## Profiles

- Added more internal padding to profile-list cards.
- Kept the profile action cluster on one line with stable reserved button widths so controls no longer shift when activation state changes.
- Profile descriptions are limited to 180 characters, wrap to two lines in the selected-profile header, and elide beyond that display limit.
- Create/Edit supports outside-click dismissal when clean and an explicit discard-changes confirmation when dirty.
- Create/Edit footer actions stay right-aligned.
- Profile IDs remain generated, immutable technical identifiers and are no longer presented with a prominent copy action.

## Window chrome and navigation

- Split the old oversized top bar into a thin Windows-style title/chrome row and a separate Xenon application toolbar.
- Reworked the frameless maximize/restore control and limited the drag region so it cannot steal button clicks.
- Tightened compact-sidebar width, centering, padding, and selected-state geometry.

## Appearance and accessibility

- High text scaling now emphasizes typography rather than multiplying the entire desktop geometry. Wider settings cards remain horizontal where space allows and reflow only when the window actually becomes constrained.
- Theme backgrounds are more visible through slightly more translucent surfaces.
- The supplied theme side-assets are packaged and used for rails, corners, dividers, HUD arcs, panel frames, status marks, overlays, and subtle glow details.
- Background choices remain scoped to their matching theme.

## Asset validation

The supplied side-strip SVGs contained duplicate trailing `</svg>` tags. v7.2 repairs those copies before packaging so all included SVG resources are well-formed.

## Architecture

Game/module artwork remains separate from launcher chrome. Theme art is Xenon-owned presentation only; modules continue to supply their own game-specific art and metadata.
