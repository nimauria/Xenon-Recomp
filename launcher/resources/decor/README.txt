# Xenon UI Side Assets

This pack contains clean SVG side/decorative assets extracted conceptually from the generated UI sheet and rebuilt as separate vector assets.

Included asset types:
- side strips
- corner accents
- long and notched dividers
- HUD arc element
- diagonal slash accent
- badge/tag frame
- panel frame
- loading bar
- vertical rail
- neutral overlays (hex / diagonal lines)
- neutral status indicators and glow dot

Themes:
- amber
- green
- blue
- neutral

Notes:
- These are editable SVG assets intended for direct use in the launcher UI.
- The logo is intentionally excluded.
- Full background art should remain raster (PNG/WebP/AVIF), not SVG.
